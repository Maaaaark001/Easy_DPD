# 算法审查报告（Easy_DPD Python 版）

> 审查对象：原 MATLAB 仓库（`main_detail.m` 及其函数）及其 Python 移植（`easydpd/`）。
> 结论先行：**整体算法正确**，属经典 ILA（间接学习架构，Indirect Learning Architecture）DPD；
> 存在若干可改进点，均不影响当前仿真的有效性。

## 1. 架构与正确性确认

| 环节 | 实现 | 审查结论 |
|---|---|---|
| PA 失真模型 | `distortion` = FIR 记忆效应 + Saleh 无记忆非线性 | ✅ 正确。Saleh 系数 `[1.5 0.5 π/3 1]` 为经典经验值，AM/AM 与 AM/PM 公式无误；FIR 抽头 `[0.7692 0.1538 0.0769]` 模拟轻度记忆效应 |
| 基函数构造 | `mp_model(x, K, M)`：列 = `x[n-m]·|x[n-m]|^k`，m=0..M，k=0..K | ✅ 正确。列序与 MATLAB 版一致；`mat_delay` 的 `circshift+置零` 等价于因果前向延迟（尾部无污染） |
| 逆模型拟合 | `w = pinv(Y'Y)·Y'·x` → `lstsq(Y, x)` | ✅ 数学等价（均为最小二乘解）。SVD 求解比正规方程对病态矩阵更稳、更快 |
| 预失真输出 | `x_pre = U·w`（U 为目标信号的基函数） | ✅ ILA 标准做法 |
| 评估 | `NMSE`、加窗 FFT 频谱 | ✅ 定义标准 |

**端到端结果**（N=16384，K=5，M=3）：

| 指标 | 数值 | 说明 |
|---|---|---|
| 失真本底 NMSE | −6.78 dB | 未补偿的 PA 失真水平 |
| 模型拟合 NMSE | −25.29 dB | GMP 对 PA 特性（AM/AM、AM/PM）的拟合精度 |
| 补偿后（同频） | −50.27 dB | 预失真后带外失真压制约 50 dB |
| 补偿后（泛化 89/111 kHz） | −50.40 dB | 系数对新频点信号同样有效，泛化良好 |

## 2. 发现的问题与改进建议

### P1（中）MP 模型包含偶次项，可只保留奇次项
`mp_model` 的 k 取 0..K 全阶次。其中 k 为奇数时对应 `x|x|^k` 是 **2、4、6 阶偶次项**：
对窄带（带通）信号，偶次项产生的分量落在 DC 和 2 倍频附近，**对带内线性化没有贡献**，
只会增加矩阵列数（K=5, M=3 时 24 列 → 12 列）与条件数，降低数值稳定性。

- 窄带 DPD 的标准做法：只保留奇次项（k = 0, 2, 4, …，即 1、3、5 阶）。
- 若信号是实宽带信号，则必须保留偶次项。
- 当前仿真中影响有限（24 列 × 16384 行超定，解稳定），但建议窄带场景按奇次项建模。

### P2（中）缺少时延对齐（delay alignment）
PA 输出 `y` 与输入 `x` 直接逐点对齐用于拟合。实际中 PA 的群延迟会使 `y[n]` 对应
`x[n−τ]`，ILA 拟合未对齐会有偏。本仿真中 FIR 主抽头居首、记忆很浅，影响可忽略；
**工程实现必须**先用相关法估计延迟 `τ = argmax |corr(x, y)|`，对 `y`（或 `x`）移位对齐后再拟合。

### P3（低）采样时间轴定义不严谨
`t = linspace(0, N/fs, N)` 的间隔为 `N/(fs·(N−1)) ≈ 1/fs`，最后一个采样点超出 `(N−1)/fs` 一个采样周期。
建议改为 `t = np.arange(N) / fs`。对频谱分析结果影响极小（正弦频率本就不是 DFT bin 的整数倍），但定义更严谨。

### P4（低）`plt_fft` 只画 `real(x)` 的频谱
对实数带通信号合理（实部含全部信息）；若信号为复数基带（IQ），应直接画 `|X(f)|`。
建议在使用复数基带信号时改用复信号 FFT。

### P5（低）评估指标可补充 ACPR
目前只有 NMSE 与频谱目视。工程上更常用的量化指标是 **ACPR（邻道功率比）**：
主信道功率 / 邻信道功率（dBc），可直接从 `plt_fft` 的 PSD 计算。需要时可补充。

### P6（信息）仓库内两个主脚本不一致
`main.m` 为旧版（K=7、M=3、无泛化测试），`main_detail.m` 为现行版（K=5、M=3、含泛化测试）。
README 已注明以 `main_detail.m` 为准，Python 版也只复刻 `main_detail.m`。

## 3. Python 重写的加速点

- **向量化**：Saleh、NMSE、延迟、基函数全部用 numpy 数组运算，无 Python 级逐点循环。
- **`mp_model` 递推构造**：`term *= |x|` 递推生成各阶次，避免对每列重复做幂运算；矩阵一次性预分配。
- **`lstsq`（SVD）替代正规方程**：数值更稳（病态矩阵下不发散），速度由 LAPACK 保证。
- **`scipy.signal.lfilter`**：与 MATLAB `filter` 语义一致的 FIR 滤波。

当前规模（N=16384，P=24）单次运行 < 1 s。若未来需要大规模样本（N≥10⁶），可选：
正规方程 + Cholesky 分解（更快）、`scipy.sparse.linalg.lsqr`（迭代）、numba 加速基函数构造。
